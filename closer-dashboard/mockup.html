Rebuilding this in FGFunnels

FGFunnels dashboards are edited in-app: open the Closer Dashboard, click Edit (pencil, top right), then add and arrange widgets. The map below recreates the layout above using the native widget library. Every appointment widget draws from the same source — Appointments — and differs only by its status condition, so the counts always reconcile.

Revenue and cash collected are two different numbers — show both, never merge them. Revenue is the full contracted value of every deal closed in the period: a $2,600 offer on a 4-pay plan counts as $2,600 the day it closes. Cash collected is only the money that actually hit the account this calendar month — deposits, installments landing from earlier months' deals, paid-in-fulls. They also run on different clocks: revenue follows the dashboard's selected date range, cash collected is month-to-date. Expect them to disagree; the gap between them is your outstanding payment-plan balance.
Pick one show-rate formula and keep it everywhere. This mockup uses shows ÷ (booked − cancelled) — "due to run" — so cancellations don't inflate the no-show rate. If your team counts it as shows ÷ booked instead, that's fine, but make every widget and every closer conversation use the same denominator.

Widget map, top to bottom

TileWidget setup
Revenue Source Opportunities → metric Sum of opportunity value, condition Status is Won, date property = the date the opportunity was won. For this to include payment plans, the opportunity's value must be the full contracted amount at close — not the deposit. Make it the widest widget in the top row and add the comparison toggle ("vs. previous period") so the delta shows.
Cash collected Source Payments / Transactions → sum of successful payments, date range fixed to month-to-date (independent of the dashboard's range). This picks up installments from prior months' deals automatically. If payments don't run through FGFunnels (e.g. cash lives in your Daily Cash Report), leave this tile off rather than showing a number that doesn't reconcile.
Deals closed / Avg deal size Opportunities → Count, Status is Won; and Average of opportunity value, Status is Won.
Booked Appointments → Count, no status condition (or exclude Invalid), date = appointment start date in range.
Confirmed Same widget, condition Status is Confirmed.
Cancelled Same widget, condition Status is Cancelled.
No-shows Same widget, condition Status is No-show. This only works if closers actually disposition every call — see the note below.
Show-up / no-show rate The dashboard builder doesn't divide one widget by another. Three options, best first: (1) newer FGFunnels builds include percentage metrics on the Appointments source — check the metric dropdown for Show rate / No-show rate before assuming it's missing; (2) use the native Reporting → Appointment report, which computes both rates, and link it from the dashboard; (3) place the Showed and No-show count tiles adjacent so the ratio is readable at a glance.
Closer close rate Opportunities → Conversion / win rate metric (won ÷ total in period). For per-closer tiles, duplicate it with condition Owner is [closer] — one small widget per closer, side by side.
By closer Two mirrored widget columns (one per closer), each: held calls (Assigned user is [closer], Status is Showed), won count, won value. FGFunnels has no native table widget, so mirrored columns are the clean substitute.

Layout rules that make it look designed

RuleWhy
Revenue leads, cash beside itRevenue gets the biggest widget at top-left; cash collected sits directly beside it one step smaller, so the pair reads together without competing. Nothing below the top band gets hero sizing.
Counts row, then rates rowRaw counts (booked / confirmed / cancelled / no-show) in one row of four equal tiles; rates in the row beneath. Never mix a count and a percentage in the same row — the eye can't compare them.
Four tiles per row, equal widthResize each widget to a quarter width. Uneven tile widths are most of why the current dashboard feels messy.
Delete everything elseAny widget not in the map above moves to a second dashboard or gets removed. A closer dashboard answers exactly: did they show, did we close, what's it worth.
Set the dashboard's default date rangePick the range the team actually reviews (weekly or 30-day) so it opens on the right numbers without clicking.
The data hygiene that makes all of this true: every held call must be dispositioned (Showed / No-show / Cancelled) same-day, and every closed deal needs its opportunity moved to Won with the real contracted value. The rates on this dashboard are only as honest as those two habits.
