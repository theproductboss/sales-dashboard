# Registers: The Skill's Memory

Create these three files in the user's working folder on first use (or as one document with three sections if they prefer). Update them after every review. Without them, nothing compounds and nothing can be ranked.

## 1. Call log

One row per reviewed call.

| Date | Rep | Prospect (initials) | Call type | Score | Grade | Outcome | Flags | Turning point (mm:ss + 5 words) | Root cause of loss | Drill assigned |
|---|---|---|---|---|---|---|---|---|---|---|

After 20+ rows, run the calibration check: average score of closed calls vs lost calls, and which dimensions separate them most. Write the result into the playbook amendments.

## 2. Rep profiles

One section per rep.

```
REP: [name]
Calls scored: [N] · Avg score: [NN] · Close rate on scored calls: [NN%]
Strongest dimension: [x] · Weakest dimension: [x]
Recurring pattern: [one line, with the call dates that show it]
Current drill: [drill] · Assigned: [date] · Next check: [date]
Wins to repeat: [best clips with call + timestamp]
History: [dated one-liners: "2026-11-12 drill passed, moved to label drill"]
```

## 3. Playbook amendments

Dated house rules that override the generic frameworks.

```
[DATE] · Source: [manager correction / outcome data / exemplar call]
Rule: [the rule, stated plainly]
Why: [the evidence]
Replaces: [which default in the references it overrides, if any]
```

Also kept here:

- **Benchmark call:** the gold-standard call and its score.
- **Exemplar index:** 90+ closed calls, best moment per stage.
- **House objection library:** objection wording → response that worked → call, rep, outcome → times it's worked.
- **Weight changes:** any change to the scorecard weights, with the data behind it.
